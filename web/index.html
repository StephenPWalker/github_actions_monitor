Connect your account

Credentials stay on your machine.

Already using GitHub CLI? Run gh auth login, then enter your username above.

  1. Install Rust 1.87+ and GitHub CLI 2.49+ on this machine. Start this app with cargo run --locked.
  2. Run gh auth login --hostname github.com --web --scopes repo,read:org,admin:org in a terminal and complete GitHub’s sign-in. For an existing login, add organization access with gh auth refresh --hostname github.com --scopes read:org,admin:org. Check it with gh auth status.
  3. Enter your personal GitHub username, even for organization runners. Leave the token blank to use your CLI session. A fine-grained token needs Actions: read and Administration: read for repositories. For organization runners, choose the organization as the token’s resource owner and grant Self-hosted runners: read. Organization approval, an appropriate organization role, and SSO authorization may be required.
  4. Click Connect account. Personal and accessible organization repositories are included automatically. Optional repository names restrict polling; use org/repo for organization repositories. Organization runners are shared pools, counted once.

The app makes read-only requests through gh. It never saves a token to disk, cookies, or browser storage. Disconnect clears the form and in-memory connection. Your existing CLI login is managed separately by GitHub CLI.
